# Python Weather

Simple Python script that reads cities from `Cities.txt`, fetches current temperatures from the wttr.in API, and groups the results by country. Written for VK interview

## Run

1. Open a terminal in the project folder.
2. Run:

```bash
python main.py
```

or:

```bash
python3 main.py
```

## Notes

- The app reads city names from `Cities.txt`.
- It uses the internet to fetch weather data from wttr.in.
- No extra dependencies are required.
